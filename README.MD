# Tropical Cyclone Rapid Intensification Prediction

In this tutorial, we learn how machine learning can be used to predict **rapid intensification (RI) of tropical cyclones**. We build a dataset from historical tropical cyclone observations and reanalysis data, define a 24-hour RI prediction task, and investigate how storm evolution and environmental predictors contribute to RI prediction.
